RESUMEN

He copiado P1-base al subdirectorio P1-base-ex y le he anyadido el campo
"credito" (BooleanField) al modelo Pago. El pago se marca como credito
(True) cuando el titular de la tarjeta es exactamente "Clodoveo Martinez
Dans" y como no credito (False) en cualquier otro caso. Las plantillas
muestran el nuevo campo al registrar el pago y al listar pagos desde
testbd.

He probado todo en una sola MV (MV1) con la BD local; no he usado el
cluster.


CAMBIOS REALIZADOS

1. visaApp/models.py - Anyadido el campo credito al modelo Pago:

       credito = models.BooleanField(default=False)

2. visaApp/views.py - He importado Tarjeta y definido la constante con
   el nombre del titular que activa el credito:

       from visaApp.models import Tarjeta
       NOMBRE_CREDITO = 'Clodoveo Martinez Dans'

   En aportarinfo_pago (flujo normal: tarjeta -> pago), tras leer
   numeroTarjeta de la sesion, busco la Tarjeta y comparo el nombre:

       try:
           tarjeta_obj = Tarjeta.objects.get(numero=numero)
           pago_data['credito'] = (tarjeta_obj.nombre == NOMBRE_CREDITO)
       except Tarjeta.DoesNotExist:
           pago_data['credito'] = False

   En testbd, el nombre viene directamente del formulario:

       data['credito'] = (
           tarjeta_form.cleaned_data['nombre'] == NOMBRE_CREDITO)

3. template_exito.html - Anyadida una linea para mostrar el campo:

       <p> Crédito: {{ pago.credito }}

4. template_get_pagos_result.html - Anyadida la columna "Crédito" en la
   cabecera y en cada fila de la tabla del listado.

5. visaApp/migrations/0002_pago_credito.py - Migracion generada con

       python manage.py makemigrations visaApp
       python manage.py migrate

   Anyade la columna credito (boolean, default=False) a la tabla pago.


PRUEBAS

He registrado 5 pagos via testbd con tarjetas de distintos titulares
para cubrir todos los casos:

  Pago 1: Clodoveo Martinez Dans   -> credito = True
  Pago 2: Clodoveo Martinez Dans   -> credito = True (otra transaccion)
  Pago 3: Gabriel Vallejo Cozar    -> credito = False
  Pago 4: Petra Martinez Dans      -> credito = False
                                      (Martinez Dans pero NO Clodoveo)
  Pago 5: Clodoveo San Poza        -> credito = False
                                      (Clodoveo pero NO Martinez Dans)

Los casos 4 y 5 son los mas relevantes: demuestran que la comparacion
es por igualdad exacta del nombre completo. Ni un Clodoveo distinto, ni
un "Martinez Dans" con otro nombre, activan el credito.
